# 독극성물질연구센터 · 연구 지식 허브 (NPCC 설계 프로토타입)

한국 국가 단위 독극물 통제센터(NPCC) 설계를 위해 조사한 자료를 한곳에 모아 둔 **단일 HTML 파일** 프로토타입입니다.
`index.html` 하나에 화면, 데이터, 실행에 필요한 스크립트(React 18.3.1 포함)가 모두 들어 있습니다.

> **연구 프로토타입입니다. 의료 조언이 아니며, 실제 신고·상담·진료 서비스가 아닙니다.**
> 응급 상황이면 즉시 **119**에 연락하세요.

## 열어 보기

- GitHub Pages가 켜져 있으면: `https://hyunjeongshin83.github.io/npcc-research-hub/`
- 주소 끝에 `?clean`을 붙이면 상단의 '시안'(색상·화면 크기 전환) 막대 없이 열립니다.
- 내려받아 열기: `index.html`을 브라우저로 엽니다. 서버가 필요 없습니다. 글꼴(Pretendard, IBM Plex, Noto Serif KR)만 CDN에서 받고, 오프라인이면 시스템 글꼴로 표시됩니다.

## 들어 있는 것

연구 지식 허브 27개 탭(3개 그룹)과 검색·탐색 화면입니다. 상단 `전체메뉴`의 모든 하위 항목은 해당 화면·탭으로 바로 이동합니다. 탐색기의 건수는 원본 표(CSV)와 대조해 일치함을 확인했습니다.

| 탐색기 | 건수 |
|---|---|
| 독성 자료 카탈로그 | 532 (실제 자원) |
| 사례 | 178 |
| 국가 비교 | 65 (OECD 38, 비OECD 27) |
| AI 근거 | 79 |
| 문헌 | 1,029 |

그 밖에 식품의약품안전평가원 독성정보제공시스템(Tox-Info)과의 메뉴·기능 비교(웹 검색 결과 기준), 해외 운영 사례, 체내 독성·검체·산업 독성 자료, 장기·내분비·내피 유전자 발현 분석, 제품 입력 스키마, AI 안전성 평가 설계, 표본 크기 계산기, 식별자(GTIN·CAS) 검사 위젯이 있습니다.

## 반드시 알아둘 점

- 허브의 글은 **연구 보고서 요약**이며 근거 등급(확인/부분/미확인)을 함께 적었습니다. 미확인 항목은 인용 전에 원문을 확인하세요.
- **센터 소개, 연구 성과, 신고·상담, 공지, 통계, 내 생활 기록** 화면은 디자인용 **예시(샘플) 데이터**입니다. 실제 기관 소식이나 접수 화면이 아닙니다.
- 독성 자료 카탈로그는 **출처·접근 조건 같은 메타데이터와 링크**만 담습니다. 제한·등록·상용 자료의 원자료는 포함하지 않으며, 각 출처의 이용약관을 따라야 합니다.
- [독성정보제공시스템(Tox-Info)](https://www.nifds.go.kr/toxinfo/Index.do)의 내용은 복제하지 않았고 링크만 연결했습니다.
- AI 보조 기능은 실행 환경에 해당 기능이 없으면 내장 예시 응답으로 대체됩니다.
- 응급 선별 규칙(119/109 연결)은 이 파일에 들어 있지 않습니다. 별도 서비스 패키지에 초안으로만 있으며 전문가 검증 전에는 사용하면 안 됩니다.

## 검증 범위

jsdom(가상 DOM) 환경에서 27개 탭 렌더링, 탐색기 건수, 위젯 동작, 전체메뉴 하위 항목 이동 53개 점검, 오류 0건을 확인했습니다. 실제 브라우저(Chrome·Safari)에서의 시각 확인과 접근성 점검은 하지 못했습니다.
